# Nail Revolution — editable website

A buildless HTML/CSS/JavaScript website. Open dist/index.html, or run `python3 -m http.server 4173 --directory dist` and visit http://localhost:4173. No install or build required.

## Edit
- dist/index.html: homepage, navigation, service summaries, contact details and structured data.
- dist/style.css: responsive design, colours and typography.
- dist/script.js: mobile menu, gallery lightbox and copy-enquiry interaction.
- dist/menu.html: published historical price reference.
- dist/nailacademy*.html: original course curricula.
- dist/assets: local brand photography; provenance in research/assets.json.
- research/CONTENT-AUDIT.md: readable extraction of all 12 original pages.
- research/extraction.json: original titles, metadata, headings, text and image URLs. Original page HTML is retained alongside it.
- dist/content-notes.html: source verification, editorial content and missing confirmations.

## Booking
Call and Instagram links contact the real source-listed business. No form pretends to send or confirm a booking. Copy enquiry only copies a message locally. No personal data is collected or stored.

## Public launch
Confirm business details, price list, course claims, image/client permissions and target domain. This is a private redesign preview with noindex and robots disallow. Remove both blocks only for an approved public launch. Add final canonical URLs, og:url and sitemap; apply research/url-migration.json at the old host where possible. The Wix subdomain cannot be redirected from this project. Preserve source keywords naturally; no ranking guarantees. Verify www.nailrevolution.in (linked by Instagram) before selecting the production domain.

Fonts use Google Fonts with Georgia/Arial fallbacks. Photos are local and no Instagram tracker/embed is loaded.
